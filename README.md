# Encuadrado

Encuadrado es una página creada por Derek Suarez. Su emprendimiento se basa en un sitio web para la venta de cuadros y el enmarque de fotos familiares, con el fin de guardar y preservar recuerdos de forma física, para que las personas tengan recuerdos tangibles de momentos importantes de su vida.

## Cómo ejecutarlo

1. Instala Node.js (versión 18 o superior).
2. En la carpeta del proyecto ejecuta `npm install`.
3. Ejecuta `npm start` y abre http://localhost:3000

Mientras desarrollas puedes usar `npm run dev`, que reinicia el servidor al guardar cambios.
